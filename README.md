# 파인애플의 전설 다국어 오디오북

목포여자상업고등학교 글로벌 동화책의 필리핀어·영어·몽골어·스페인어 및 한국어 낭독 웹사이트.

정적 HTML과 원본 영상·음성으로 동작합니다. 클로드 계정이나 구독, Google Drive 재생기가 필요하지 않습니다.

GitHub Pages: main 브랜치의 /(root)를 게시합니다.

언어 바로가기: #tl, #en, #mn, #es. 듣는 방법: /book, /audio, /subtitles.

기존 제작물의 영상과 음성은 재인코딩 없이 그대로 사용했습니다. cover.jpg는 각 책 영상의 첫 장면입니다. 필리핀어 원어민 낭독은 표지~5쪽 분량이며 한국어 전체 낭독이 이어집니다.

2026-11-19 한국어 재생 수정: 한국어 구간을 언어판별 책 영상·음성·자막 영상으로 분리했습니다. '한국어만 듣기'는 해당 한국어 전용 파일을 0초부터 재생합니다. 원어 파일의 중간 위치로 이동하지 않습니다. 한국어 직접 링크는 #tl/book/ko, #en/audio/ko 등의 형태입니다. 기존 원어부터 이어 듣기 파일은 보존했습니다.
